## Flujo recomendado para probar la app

1. Abre la app Android en el emulador
2. Pulsa "Registrarse" y crea una cuenta nueva
3. Se activa la cuenta automaticamente desde MailHog → http://localhost:8025
4. Inicia sesión con las credenciales creadas
5. Completa el formulario de perfil
6. Explora la pantalla "Para Ti" con tu plan personalizado
